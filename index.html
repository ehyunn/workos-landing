🔄 Sinkronisasi antar device

    
localStorage tidak sinkron otomatis antar HP/laptop. Solusi: export file workos-backup.json dari device A → import di device B. 10 detik.

    

      
      
    

    
Alur tipikal: selesai kerja di laptop → Export → buka HP → Import. Sebaliknya juga sama. Export dulu sebelum import — import menimpa data device tujuan.

    
Alternatif tanpa ribet: kerja selalu dari 1 device, device lain cuma buat lihat.
